# Lens: a text an agent will read (a prompt, a tool description, a tool's output, a rule)

Read it from the agent's seat, at the moment it arrives.

1. When does the agent read this, and what does it know at that moment? What does the text assume that the agent has not seen?
2. What is the strongest sentence, and the last one? That is what it will follow. Is that the sentence you mean?
3. Does it contradict another text the agent holds? Then the fault is in the texts, not in the agent.
4. Is each thing you want done a numbered step whose answer must be written, or a line in a list it can pass over?
5. What new way out does it open: can the agent satisfy the words without doing the work?
6. Does a general text carry a word of one job or one customer? Move it to that job's own text.
7. How will you see that it changed the agent's behaviour? A text that changes nothing is removed.

Write the expected outcomes as what the agent will do differently, in a case you can run.
